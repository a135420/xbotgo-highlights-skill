# XbotGo 足球比赛集锦

把一场或多段本地比赛 MP4 整理成带时间标签的回放、射门集锦或指定门将集锦。Codex 通过一个技能 `xbotgo-highlights` 调用本机脚本。模型负责提出候选，复核时看原片中的触球、球路、门线和球员身份。

## 周六录完怎么用

把录像放进一个文件夹，在 Codex 里给出文件夹或单个 MP4 的路径，再选一种说法。可把三种任务写在同一条消息里。

| 想要的结果 | 可以直接这样说 | 用到的能力 |
|---|---|---|
| 双方进球回放 | “用 xbotgo-highlights 扫这个文件夹的双方疑似进球，给我能点时间的回放页。” | sn-spotting 的 CALF 提取进球候选，附源内时间和模型分数。 |
| 我方射门和进球 | “我方穿白衣，上半场向厂房端进攻，下半场换边。找我方射门，确认的进球单独剪。” | sn-teamspotting 判断动作和场上左右队；用球衣、进攻方向和换边时间把左右队映射到我方。 |
| 指定球员或门将 | “剪这个门将的扑救和出击。第一段 02:15 站在左侧门前的是他。” | sn-tracking 路线给可见球员分配轨迹 ID。用参考画面确认人物，复核触球和扑救，再剪片。 |

只筛候选就交付回放和标签；要求成片时，从确认项剪辑，疑似项单列。若录像同时有原版和裁掉开头的副本，请指定使用哪份。每个标签以选中的源文件起点计时。

## 安装与运行

1. 下载 [v1.3.0 技能包](releases/xbotgo-highlights-v1.3.0.zip)，解压，把里面的 `xbotgo-highlights` 文件夹放进 `~/.codex/skills/`。已有安装时先保留自己的本地改动。
2. 准备 Python、FFmpeg（含 ffprobe 和 libx264）。可选模型有独立的安装步骤；只启用需要的入口。权重与依赖存放在技能目录之外，比赛原片在本机处理。
3. 在新会话中输入上表的任意一句并附录像路径。命令行用法见各任务说明。

| 任务说明 | 阅读时机 |
|---|---|
| [进球候选与回放页](xbotgo-highlights/references/soccernet.md) | 第一次用 CALF，或需要 CSV、JSON 和可跳转回放。 |
| [球队动作识别](xbotgo-highlights/references/teamspotting.md) | 需要区分哪队射门或进球。 |
| [球员跟踪](xbotgo-highlights/references/tracking.md) | 需要查看跟踪编号或选定某名球员。 |
| [多原片工作台](xbotgo-highlights/references/session-workflow.md) | 需要球门审核、跨文件台账、分类导出及音视频校验。 |
| [普通高光初剪](xbotgo-highlights/references/workflow.md) | 需要快速音频候选、全场抽样或分享分段。 |

## 本版实测

在 Apple Silicon Mac 上用夜场 XbotGo 原片做了三项验证。

| 入口 | 实测结果 |
|---|---|
| CALF | 16 分 32 秒录像生成 4 个疑似进球。回看对应攻防过程，没有足够画面证据确认进球。 |
| T-DEED | 12 秒样本输出 11 条传球或带球候选。另取包含已复核射门的 16 秒样本，默认阈值下没有报出射门。找全射门时仍需检查原片。 |
| ByteTrack | 4 秒样本按每秒 4 帧跑通，生成 347 条人员框记录；在浏览器验证了叠框、筛选编号和跳转。临时编号会包括场边人员，也可能在跟踪中变化。 |

## 版本迭代

| 版本 | 这次增加了什么 | 使用上的变化 |
|---|---|---|
| v1.3.0 | SoccerNet 赛后分析入口 | 可先按进球、球队动作或球员轨迹找片段，再回到原片复核。 |
| v1.2.0 | 球门审核页、多原片事件台账、连续回放、分类导出 | 同一批原片可以分别导出射门、门将和进球合集，并追溯每段来源。 |
| v1.1.1 | 补全射门、射偏、封堵与空场的判断说明 | 复核时区分明确动作、疑似动作和可排除片段。 |
| v1.1.0 | 首个独立安装包，加入全时间轴抽样和音频高光初剪 | 从多段原片建立时间索引，保留原声和动作前后过程。 |

逐版验证与完整变更见 [CHANGELOG](xbotgo-highlights/CHANGELOG.md)。确认射门和进球的依据见 [画面判断规则](xbotgo-highlights/references/judgment.md)。
