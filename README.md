# 足球比赛集锦 Skill

处理 XbotGo 或其他足球比赛 MP4：生成音频高光初剪，通过全时间轴复核整理射门集锦，保留原片时间和疑似攻门。

当前版本：**v1.1.1**。射门与空场尾段需要连续画面复核；不承诺全自动、无遗漏识别。

## 射门判断逻辑

处理顺序：**全场补查 → 动作复核 → 疑似保留 → 加长剪辑**。

1. **从全部原视频开始**：按拍摄时间排序，默认检查全片。用户指定比赛起止时按本次设置处理；连续画面确认比赛结束且持续空场后，才排除尾段，保留范围和依据。
2. **先确定比赛球门**：确认本场两端比赛大门，排除训练小门。固定机位左右跟拍时，可用大门周边背景特征辅助定位；球门位置只帮助找进攻区域。
3. **沿全场时间轴补查**：建议每2秒抽一帧找进攻，不局限于声音或原先候选；重点动作再用每秒2至4帧连续画面复核。
4. **结合动作和球路判断**：看起脚／争顶是否朝比赛门、球离开后朝哪里走、是否遭封堵，结合门将响应判断；远射、射偏和被挡的攻门也可保留。门将响应是辅助证据，不是每次射门必须具备的条件。
5. **保留完整过程**：通常从动作前12秒剪到后8秒，连续攻门延长并合并重叠区间，按原片时间顺序输出并保留来源索引。

| 复核结论 | 判断依据 | 输出处理 |
| --- | --- | --- |
| 明确攻门 | 可见向比赛门的射门或争顶动作，并有方向、后续球路或封堵等证据相互支持 | 放入主集锦，不据此宣称进球 |
| 疑似攻门 | 最后触球被挡、关键动作未入画，或无法分清射门与传中 | 单独保留“待复核攻门”，记录不确定原因 |
| 排除 | 连续画面明确为普通传球、开球、等待重开或已确认的空场 | 从本次集锦排除，保留原素材及复核依据 |

**不能单独作为射门结论的线索**：声音大、靠近球门、门将倒地、禁区多人聚集。未看清动作时先留待复核；“没有检测到球”不等于“没有射门”。

上述是 agent 查看连续画面的复核规则。当前脚本负责音频候选、时间轴抽样和剪辑；比赛门定位、足球跟踪及射门语义识别尚未集成为全自动算法。详细边界与例子见 [判断规则](xbotgo-highlights/references/judgment.md)。

## 下载与安装

[下载 v1.1.1 skill 压缩包](releases/xbotgo-highlights-v1.1.1.zip)

解压后，把 `xbotgo-highlights` 目录放入 `~/.codex/skills/`，新开会话后说“用 xbotgo-highlights 处理这些足球录像”。

需要 Python 3.9+、ffmpeg/ffprobe；全时间轴抽样另需 Pillow。详细步骤见 [操作说明](xbotgo-highlights/references/workflow.md)。

## 使用示例

```bash
python3 xbotgo-highlights/scripts/highlight_tool.py auto /path/to/match.mp4 --out-dir /path/to/result --profile sevens
```

此命令是音频高光初剪入口。射门补漏、空场复核及加长剪辑请按 [SKILL.md](xbotgo-highlights/SKILL.md) 执行。
