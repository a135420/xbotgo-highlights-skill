# 足球比赛集锦

先区分用户要“比赛高光”还是“射门集锦”。所有路径相对于本 skill 目录，工具随包提供，运行时使用实际素材路径。

## 使用条件与能力

需要 Python 3.9+、ffmpeg/ffprobe（含 libx264）。macOS 可用 `brew install ffmpeg`。全时间轴图另需 Pillow，按 [操作说明](references/workflow.md) 建独立环境安装。

- `scripts/highlight_tool.py`：音频候选扫描、CSV/JSON、剪辑、复核页、分享分段；音频候选需要画面复核才能称为射门。
- `scripts/timeline_review.py`：多文件按拍摄时间排序、全时间轴抽样图、源内时间与逐帧索引。它负责提供复核材料，动作判断由 agent 查看连续画面完成。
- 比赛门定位、足球跟踪及射门语义识别尚未集成到这些脚本。固定机位的背景匹配可作为场景方案，详见操作说明。

## 处理流程

1. 列全本次原片，按拍摄时间排序，核对时长。默认检查全片。用户指定比赛范围时单独记录起止与来源；文件名无时间时依据素材信息确定顺序。
2. 检查赛前、暂停和空场尾段。只有连续画面支持“比赛结束、持续空场”，才排除对应区间，记录文件、起止时间、依据与复核状态。有人暂时出画、镜头转偏、识别不到球、音量低时保留未知。原视频始终保留。
3. 按本次场地确认比赛两端大门与机位，区分场边训练小门。七人场使用本场标线和视角；球门位置用于找进攻，不能直接作为射门结论。
4. 生成候选与全时间轴复核材料。射门集锦及补漏任务沿全部比赛范围抽样检查（建议每2秒一帧），重点动作再用每秒2至4帧连续画面核对，不只看音频候选。登记已复核范围与尚未复核范围。
5. 结合起脚或争顶方向、球路、封堵和门将响应判攻门；远射也保留。普通传球、开球和等待重开排除。遮挡、射门与传中难分的，另存“待复核攻门”，保留证据与原片时间。进球结果单独确认。
6. 从原视频剪辑，默认建议动作前12秒、后8秒，可按用户要求调整；连续攻门延长并合并重叠区间。完整射门任务不设固定8段、40段或按每个文件分配名额。按拍摄时间合并，保留现场原声。
7. 输出合集、单片或复核页、CSV/JSON来源索引，附复核范围与局限。检查音画、解码、时间顺序、范围和本地资源；超过14分钟按素材边界分享分段。技术检查与射门内容验收分别说明，不承诺无遗漏。

确认射门、射偏、封堵、争顶与空场边界时读取 [判断规则](references/judgment.md)。

具体命令、空场处理、射门复核记录及导出参数见 [references/workflow.md](references/workflow.md)。

## 普通高光入口

```bash
python3 scripts/highlight_tool.py auto "/path/to/match.mp4" \
  --out-dir "/path/to/result" --profile sevens
```

此入口生成音频高光初剪。`sevens` 是七人场候选预设；`balanced/precise/strict` 调整音频候选数量，不能替代动作复核。漏射门反馈应扩大时间轴复核范围，不能只提高阈值。所有预设默认从0秒检查，开头和结尾范围仅按本次配置排除。
