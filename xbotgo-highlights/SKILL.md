# 足球比赛集锦

先明确本次要比赛高光、双方/我方射门、进球还是指定门将；用户已说明时直接沿用。所有路径相对于本 skill 目录，素材与任务输出保存在单独工作目录。

## 使用条件与能力

需要 Python 3.9+、ffmpeg/ffprobe（含 libx264）。macOS 可用 `brew install ffmpeg`。全时间轴图另需 Pillow，按 [操作说明](references/workflow.md) 建独立环境安装。

- `scripts/highlight_tool.py`：音频候选扫描、CSV/JSON、剪辑、复核页、分享分段；音频候选需要画面复核才能称为射门。
- `scripts/timeline_review.py`：多文件按拍摄时间排序、全时间轴抽样图、源内时间与逐帧索引。它负责提供复核材料，动作判断由 agent 查看连续画面完成。
- `scripts/match_session.py`：多原片任务台账、球门拖框审核页、复核范围、连续短片与缓存、分类合集和技术检查。多段补漏或分类剪辑时读取 [任务工作台](references/session-workflow.md)。
- 用户要赛后进球标签或回放时，用 [CALF 进球筛选](references/soccernet.md)。只要候选时可直接交付；要成片时继续复核和剪辑。
- 用户要按球队筛射门或进球时，用 [球队动作识别](references/teamspotting.md)。先记录对应时段我方球衣、攻守方向和换边，归属不明的动作保留待确认。
- 用户要指定球员或门将时，用 [球员跟踪](references/tracking.md)。将用户认可的人物参考对应到可见轨迹，出画重入、换人或编号跳变后重新核实。跟踪框本身不能证明触球、扑救或进球。
- 用户同时要求三种结果时，保留每个时间标签的原片和算法来源，在同一段连续画面上核实动作、球队与人物，再将确认项写入原有工作台。球门参考继续按场地和镜头方向审核。

## 处理流程

1. 列全本次原片，按拍摄时间排序，核对时长。默认检查全片。用户指定比赛范围时单独记录起止与来源；文件名无时间时依据素材信息确定顺序。
2. 检查赛前、暂停和空场尾段。只有连续画面支持“比赛结束、持续空场”，才排除对应区间，记录文件、起止时间、依据与复核状态。有人暂时出画、镜头转偏、识别不到球、音量低时保留未知。原视频始终保留。
3. 先取不同镜头方向的清晰参考帧，标出两端比赛门并标明场地端、我方防守端、门将身份，交给用户审核，记录其实际结论后再确认事件。本会话已有对应场地与身份确认时复用证据；缺少确认时可继续生成时间轴和不依赖身份的候选。场地A/B端与画面左右分开记录；换边、临时代班门将按时间更新。比赛大门与训练小门分别识别。
4. 沿全部比赛范围抽样检查（建议每2秒一帧），重点动作用每秒2至4帧连续图及可播放短片核对。球门区域用于优先找进攻，也保留远射、封堵与定位未知的候选。镜头转动/变焦时参考帧坐标不直接套到新画面；需补参考或保持未知。逐原片登记实际查看的范围，生成图或短片本身不算已复核。
5. 统一记录事件的源内动作时间、类别、球队/门将身份、球门参考、复核状态、依据与前后时长。射门、门将处理与进球结果分开判断，按 [判断规则](references/judgment.md) 复核；不确定项单独保留。进球需要独立的球路/门线或球门内取球等证据；中圈重开只作佐证。
6. 从原视频剪辑，默认建议动作前12秒、后8秒，可按用户要求调整；连续攻门延长并合并重叠区间。完整射门任务不设固定8段、40段或按每个文件分配名额。按拍摄时间合并，保留现场原声。
7. 从同一台账筛选分类合集，确认项与疑似项分别导出。先检查每个原片的复核覆盖与入选数量；某原片为0段时说明原因，不为凑原片数量加入普通传球。局部交付明确标注尚未复核的范围。输出CSV/JSON来源索引，核对动作边界、顺序及链接，完整解码并检查音轨；超过14分钟按素材边界分享分段。技术检查与内容判断分别报告，不承诺无遗漏。

确认射门、射偏、封堵、争顶与空场边界时读取 [判断规则](references/judgment.md)。

具体命令、空场处理、射门复核记录及导出参数见 [references/workflow.md](references/workflow.md)。

## 普通高光入口

```bash
python3 scripts/highlight_tool.py auto "/path/to/match.mp4" \
  --out-dir "/path/to/result" --profile sevens
```

此入口生成音频高光初剪。`sevens` 是七人场候选预设；`balanced/precise/strict` 调整音频候选数量，不能替代动作复核。漏射门反馈应扩大时间轴复核范围，不能只提高阈值。所有预设默认从0秒检查，开头和结尾范围仅按本次配置排除。
