# 版本迭代

## 1.1.0 — 2026-10-19

首个可独立分发的打包版本。

- 脚本随 skill 提供，移除对开发者电脑固定路径的依赖。
- 区分音频高光初剪与经动作复核的射门集锦，标明现有自动化边界。
- 增加全时间轴抽样脚本，支持多原片排序、原片时间标签与复核索引。
- 所有音频预设默认检查开头0秒；比赛起止、空场排除和门框参考放在单次任务中。
- 空场尾段检查加入通用流程：连续画面确认后排除，保存起止与依据，保留未知和原片。
- 射门建议保留动作前12秒后8秒，连续攻门延长；不确定动作另留复核。
- 文件名时钟解析兼容 XbotGo 连字符格式和原有空格/冒号格式。
- 补充跨来源编码、时间基准、完整解码与交付边界说明。

### 本版验证

已通过 skill 格式校验、两个脚本的命令入口、两种文件名时钟解析、所有预设0秒起点，以及合成短视频的多片排序、全片抽样、尾帧补样和音频扫描验证。此验证不代表自动射门准确率评测。

### 本轮录像的流程演进（案例，不是三个历史软件发布版本）

- 初剪：音画候选与门区线索，40段，约21分36秒；用户反馈非射门较多。
- 第二轮：严筛动作，8段，约76.5秒；用户反馈遗漏多、上下文短。
- 第三轮：回到5个原片做全时间轴抽样和重点复核，主片39段、13分17.8秒；疑似16段、5分20秒，通常前12秒后8秒。未确认进球，不能保证射门无遗漏。
- 本次“首源从7分钟开始”和“尾部空场”的具体时间仅属于该录像任务，未写入工具默认值。

## 早期本地版本（未编号）

音频能量和瞬间变响生成候选，支持多种预设、CSV/JSON、复核页与分享分段。工具通过本机绝对路径运行，未形成独立分发包。旧预设曾默认跳过开头若干秒，已在1.1.0取消。
